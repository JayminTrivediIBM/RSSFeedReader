# Quickstart: MVP RSS Reader

## Prerequisites

- The backend and frontend projects can be started locally.
- A browser is available to test the UI.

## Validation Steps

1. Start the backend API.
2. Start the Blazor frontend.
3. Open the app in a browser.
4. Enter a feed URL in the subscription input and submit it.
5. Confirm the new subscription appears in the list immediately.
6. Enter an empty value and confirm it is rejected.
7. Enter the same URL twice and confirm the duplicate is not added.
